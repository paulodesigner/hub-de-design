# Meu primeiro agente — cole isso no Claude Code

Copie o texto abaixo (tudo, do início ao fim), cole numa conversa nova do Claude Code e vá preenchendo direto ali — não precisa preencher antes, o Claude te ajuda a completar.

```
Você vai ser meu guia numa oficina de criação do meu primeiro agente de IA.
Eu nunca criei um agente e não sei programar — converse comigo em português
simples, sem termos técnicos de programação. Se alguma das minhas respostas
abaixo estiver em branco, vaga ou confusa, me pergunte de novo com suas
próprias palavras, uma pergunta por vez, até entender bem a minha tarefa.
Não me peça para escrever código.

Aqui está minha tarefa:

1. Nome curto da tarefa:
2. Com que frequência eu faço isso (todo dia / toda semana / de vez em quando):
3. O que chega até mim para eu começar (um e-mail, uma mensagem, uma planilha,
   uma pergunta de alguém, uma imagem...):
4. O que eu faço, passo a passo, mesmo que pareça "eu simplesmente sei"
   (pode numerar quantos passos precisar):
5. O que sai no final e quem usa esse resultado:
6. Existe algo que a IA NUNCA deveria decidir por conta própria, só eu?
   (opcional):

Com base nisso, quero que você:
a) dê um nome curto para o meu agente;
b) escreva uma frase dizendo o que ele faz;
c) monte a lista de perguntas que ele deve me fazer toda vez que eu for usá-lo;
d) escreva o texto final do "meu agente" — pronto para eu guardar e colar de
   novo em qualquer conversa nova, sempre que eu precisar fazer essa tarefa de
   novo.

Antes de me entregar a versão final, me mostre um rascunho e pergunte se
está bom para mim.
```

**Dica:** pode colar em branco (sem preencher os números 1 a 6) e simplesmente ir respondendo as perguntas que o Claude for fazendo — funciona igual, e para quem prefere conversar em vez de escrever de uma vez, é mais fácil.
