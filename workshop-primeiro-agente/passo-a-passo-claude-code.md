# Passo a passo — do template ao seu primeiro agente

1. Abra o Claude Code no seu computador (o mesmo que você já usa no dia a dia).
2. Comece uma conversa nova.
3. Copie o texto completo do template (`template-para-colar-no-claude.md`, ou o quadro da apresentação).
4. Cole tudo de uma vez ali na conversa e aperte Enter.
5. Responda as perguntas que aparecerem, com suas próprias palavras — não existe resposta errada, nem resposta "técnica demais" ou "simples demais".
6. Quando o Claude mostrar um rascunho, leia com calma e diga se falta algo ou se já está bom.
7. No final, ele te devolve um texto — isso é o seu primeiro agente.
8. Guarde esse texto num lugar fácil de achar (bloco de notas, Notion, um e-mail para você mesmo).
9. Da próxima vez que precisar fazer aquela tarefa de novo, cole esse mesmo texto numa conversa nova do Claude.
